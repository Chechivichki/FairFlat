# FairFlat
FairFlat — вебплатформа для оренди та купівлі нерухомості з розумною оцінкою вартості. Сервіс пропонує пошук на карті та за фільтрами, модерацію оголошень і каталог перевірених рієлторів. Головна фіча — ML-модуль (LightGBM), який прогнозує справедливу ціну житла та допомагає відсіювати завищені пропозиції.
